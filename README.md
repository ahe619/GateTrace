# GateTrace

**Auditing Person-Level Crossing Events in Crowded Scenes**

GateTrace provides reproducible labels, evaluation tools, and event-level evidence for studying pedestrian crossings under occlusion. This package brings together the code, recorded results and an English/Chinese guide.

## Start here

1. Extract the complete folder and open [GUIDE.html](GUIDE.html) in a browser. The guide works offline; the lower-left EN / ZH button switches its language.
2. Read [START_HERE.md](START_HERE.md) for the package layout.
3. Open the [repository README](repository/README.md) for environment setup and reproducible commands. Run those commands from `repository/`.

## Read the research

- [Pipeline](repository/PIPELINE.md): inputs, outputs and commands.
- [Results](repository/RESULTS.md): numerical tables and their sources.
- [Claims and evidence](repository/docs/claims_and_limits.md): findings, scope and open work.
- [History](repository/HISTORY.md): completed and stopped research routes.
- [Verification](repository/VERIFY.md): historical checks and acceptance records.

The guide explains H1/H2, H-A/H-B, E1-E5, IVR and the pipeline variants. Historical filenames and experiment identifiers retain their original meanings. This package contains result-bearing material; human reviewers should complete their independent blind review before reading it.
