Independent crossing-clip review

Judge the evidence visible in the video. Complete your review independently, without viewing other reviewers' answers.

Use the box to locate the person and judge visibility from the video itself. The line is the gate line under review. Relative time 0 marks the reference crossing frame; inspect the actual footage before and after 0 separately. Choose Uncertain when the image is unclear or you cannot distinguish the target.

Each code has separate answers stored in this browser. Use the unique code assigned by the organizer and import only your own backups. Browser storage may be cleared, so download backups regularly. Answers stay on this device.

Space: play/pause; ←/→ or ,/.: step one frame; [/]: previous/next item. Scroll to zoom, then drag to pan.

1. Before the crossing, was any part of this person visible?

Assess only the footage before the reference time. You must be able to attribute the visible part to the person indicated by the box.

2. After the crossing, was any part of this person visible?

Assess only the footage after the reference time. You must be able to attribute the visible part to the person indicated by the box.

3. Did this person actually cross this line?

Base your answer on the actual footage. Markers and the reference time identify what to review. Choose Uncertain if only the GT box crosses and the original images cannot confirm that this is the person. A Yes answer requires visible evidence of the person crossing.
