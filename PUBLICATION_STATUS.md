# GateTrace release scope

Date: 2026-10-25. Distribution: complete source snapshot, authorized by the project owner for a public GateTrace repository.

The full `repository/` subtree and the existing offline guide retain their prior bytes. Source code, frozen parameters, numerical examples and reported results are unchanged. This release adds component-specific license texts, source credits and a path-bound license map. The project MIT grants remain scoped to project-authored material; GPL and AGPL conditions apply to the combinations described in [LICENSE_SCOPE.md](LICENSE_SCOPE.md).

The public SORT grant is used for inherited SORT material. No separate permissive grant or legal certification is claimed. The pinned OC-SORT MIT notice and all existing source notices remain present. Historical local-candidate status statements inside the unchanged repository describe their original delivery context.

The package contains source and numerical examples. Original video, full official GT, weights, private stadium data and human-review answers remain outside the distribution. Scientific human-QC and independent-machine reproduction retain their documented status. Public availability does not change those scientific records.

Research citations, source licensing and Git commit identity serve their respective purposes. The release preserves third-party credit and existing AI-assisted research disclosures. The owner's GitHub identity is used for the initial commit, with no Codex co-author trailer.
