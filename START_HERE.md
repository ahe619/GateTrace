# GateTrace package guide

Start with [repository/README.md](repository/README.md). Its commands run from `repository/` and explain environment setup and data layout.

| Location | Contents |
|---|---|
| `repository/` | Scientific source, configurations, tests and recorded numerical examples |
| Owner-supplied guide | Offline bilingual navigation, file descriptions, previews and research glossary |
| `PACKAGE_MANIFEST.json` | Hashes of the source distribution |

Obtain the guide ZIP from the project owner and extract it, then open its `GUIDE.html`. Complete source-file links open GitHub. The Q2/Q3 review templates have their own owner-supplied package, including unchanged pages, synthetic checks and protocols.

The package includes experimental results. The separately supplied human-review pages are empty templates; live review materials and answers follow their own protocol and are supplied separately.
