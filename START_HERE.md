# GateTrace package guide

Start with [repository/README.md](repository/README.md). Its commands run from `repository/` and explain environment setup and data layout.

| Location | Contents |
|---|---|
| `repository/` | Scientific source, configurations, tests and recorded numerical examples |
| [Standalone guide](https://github.com/ahe619/GateTrace/releases/download/guide-v1/GateTrace-guide.zip) | Offline bilingual navigation, file descriptions, previews and research glossary |
| `PACKAGE_MANIFEST.json` | Hashes of the source distribution |

Download and extract the guide ZIP separately, then open its `GUIDE.html`. Complete source-file links open GitHub. The [Q2/Q3 review templates](https://github.com/ahe619/GateTrace/releases/download/review-templates-v1/GateTrace-review-templates.zip) have their own download package, including unchanged pages, synthetic checks and protocols.

The package includes experimental results. The downloadable human-review pages are empty templates; live review materials and answers follow their own protocol and are supplied separately.
